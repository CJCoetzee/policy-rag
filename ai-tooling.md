# AI Tooling

AI tools were used to assist development and debugging.

## Tools Used

ChatGPT  
Used for:
- debugging Python errors
- understanding LangChain APIs
- generating boilerplate Flask code

GitHub Copilot  
Used for:
- code completion
- generating helper functions

## What Worked Well

- Rapid debugging of dependency issues
- Faster development of the ingestion pipeline
- Help understanding RAG architecture

## What Did Not Work Well

- Some generated LangChain code was outdated
- Required manual correction due to library version changes
- Deployment issues required manual debugging
